# PR: タスクの検索・削除・一括ステータス変更・期限切れ一覧を追加し、同時編集を検知する

## 概要

タスクが増えて目的のタスクを探しにくい、終わったタスクや誤って作ったタスクを消せない、という声に応えて、タスクの検索・削除・ステータスの一括変更・期限切れの一覧を API に追加します。あわせて、2 人が同じタスクを同時に編集したときに、後から保存した人の変更で先の変更が消えないようにします。画面の変更は別の PR で行います。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| タスクの作成者 | 記録していない | 作成した人を記録する（この PR より前に作られたタスクは作成者なし） |
| 検索 | できない | `GET /api/tasks/search?q=…&page=…&limit=…` でタイトルの部分一致検索。`page` は 1 始まり（既定 1）、`limit` は 1〜50（既定 20）。範囲外の値は 400。応答は `{ tasks, total, page, limit }`（`total` は条件に合う全件数） |
| 削除 | できない | `DELETE /api/tasks/:id`。タスクの作成者か担当者だけが削除できる（ほかの人は 403）。成功は 204、タスクが無ければ 404 |
| ステータスの一括変更 | 1 件ずつ | `POST /api/tasks/bulk-status` に `{ "ids": [1, 2], "status": "done" }`。ID は 1〜100 件。1 件でも存在しない ID があれば 404 を返し、どのタスクも変えない |
| 期限切れの一覧 | できない | `GET /api/tasks/overdue`。期限日が今日（日本時間）より前で、完了していないタスクを期限の古い順に返す |
| 同時編集 | 後から保存した内容で上書きされる | タスクに版番号（`version`）を持たせ、更新のたびに 1 増やす。`PATCH /api/tasks/:id` の本文に `version` を含めると、その版から変わっていないときだけ更新し、ほかの人が先に更新していれば 409 を返す（`version` を送らなければ従来どおり） |

すべての API はログインが必要です（未ログインは 401）。

## 検証結果

- `npm run typecheck`・`npm test`（26 件）・`npm run build` が通ることを確認した。
- 検索・削除・一括変更・期限切れ一覧の単体テストを `tests/tasks-search.test.ts` に追加した。
