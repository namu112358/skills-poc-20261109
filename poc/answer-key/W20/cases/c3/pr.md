# PR: 設置場所を場所マスタから選べるようにする

## 依頼

計測器の「設置場所」を自由入力ではなく、場所マスタから選ぶ形にしたい（品質保証部）。

## 合意した要件（依頼者との確認で決まったこと）

1. 場所マスタは品質保証部の正式な 16 か所（「部署名 + 場所」の名前）で始める。
2. 既存の設置場所は、表記ゆれ（全角・半角、第1／第一、空白、品証・品保、号車など）で同じ場所と分かるものだけ寄せる。決められない値は勝手に寄せず、元の書き方を残して「確認中」とし、確認中の計測器を一覧で探せるようにする。空欄は未設定のまま（必須にしない）。
3. 台帳での登録・編集は、場所を一覧から選ぶ形にし、自由に書けるのはやめる。
4. 場所の追加・名前の変更はログインしている人なら誰でもできる。場所は消さず、使わなくなったら「使用終了」にする。使用終了の場所は登録・編集で新しく選べないが、すでにその場所の計測器はそのまま表示する。
5. 場所の名前を変えたら、その場所にある計測器の表示も新しい名前になる。
6. ハンディ端末（協力会社製。来月まで自由入力の文字を送ってくる）からの送信は止めずに受け付ける。正式な場所と分かればその場所に、分からなければ確認中として送られた文字を残す。応答の形と認証は変えない。
7. 経理部が毎月末に DB のコピーから「設置場所」の列を直接読んでいる。来期（4 月）までは今の列を残し、場所の名前が入った状態を保つ。
8. 不具合があれば前の版のアプリに戻すことがある。DB はそのままで、前の版のアプリが正しく動く形にする。
9. 本番は約 5 万件。リリースは平日 19 時以降で再起動は 1 回、起動して使えるまで何分も止めない。移行で何件寄せ、何件が確認中になったかを後で確かめられるようにする。

## 変更内容

- 場所マスタのテーブル・既存の設置場所の移行（表記ゆれの正規化と照合。決められない値は確認中）
- 登録・編集の API と画面で、場所を一覧から選ぶ。場所の追加・名前の変更・使用終了
- ハンディ端末の受け付けで、寄せられる文字は正式な場所に、寄せられない文字は確認中に
- 使用終了の場所の計測器を、古い形式の location で確認中に戻さない
- 運用メモと、本番値との照合テスト
