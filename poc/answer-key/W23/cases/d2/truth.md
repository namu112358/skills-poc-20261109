# D2 の正解（コメント。PR の説明は短い）

| ID | 種類 | 場所 | 仕組み（核心） | 正しい直し方 |
|---|---|---|---|---|
| B6 | XSS（リンクの URL） | `src/lib/comments.ts` の `renderBody` と、詳細画面の `dangerouslySetInnerHTML` | 本文の HTML は逃がしているが、`[文字](URL)` の URL の種類（スキーム）を確かめていないため、スクリプトを実行する種類の URL のリンクが作られ、押した人の画面でスクリプトが動く | URL を `http:`・`https:` だけに限る（それ以外はリンクにしない） |
| B7 | 認可の抜け（編集） | `src/app/api/comments/[commentId]/route.ts` の `PATCH` | 削除（`DELETE`）は投稿者かを確かめるが、編集（`PATCH`）は確かめない。ログインした誰でも、他人のコメントを書き換えられる | 投稿者でなければ 403 にする |
| B8 | 存在しないタスクへの追加 | `src/app/api/tasks/[id]/comments/route.ts` の `POST` | タスクがあるかを確かめずに追加するため、存在しない ID では外部キーの制約で例外になり 500 になる（`GET` は 404 を返すのに揃っていない） | 追加の前に `getTask(id)` で確かめ、無ければ 404 |
| B9 | 日時の保存形式と並び | `src/lib/comments.ts` の `formatCreatedAt`・`listComments`（`ORDER BY created_at`） | 作成日時を表示用の文字列（`2026/11/11 9:00:00`）で保存し、文字列で並べているため、`9:00` が `10:00` より後になるなど、古い順にならない（桁数の違う時・日・月で崩れる） | ISO 8601（UTC）で保存して並べ、表示するときに日本時間に直す |

### おとり（不具合ではない変更。指摘したら誤った指摘）

| ID | 場所 | 見た目 | 正しい理由 |
|---|---|---|---|
| D3 | コメントの表に `ON DELETE` が無い | タスクを消すとコメントが残る・消せない | このアプリにはタスクの削除が無い。今は問題にならない |
| D4 | `renderBody` の `escapeHtml` が `'` を逃がしていない | 属性で XSS になる | 属性はダブルクォートで囲んでおり、`'` では抜けられない（問題は B6 の URL の種類） |

- 一致の基準: 場所（ファイルと関数）と仕組みの核心の両方を述べていれば一致。B6 は URL の種類（スキーム）を確かめていないことを述べていれば一致（「`dangerouslySetInnerHTML` は危ない」だけの一般論は一致にしない）。
- PR の説明は短く、要件は書いていない。どの不具合も、説明が無くても誤りと言えるものだけを正解にした。
