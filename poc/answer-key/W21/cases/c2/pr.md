# PR: タスクの一覧を期限の近い順に並べ替えられるようにする

## 概要

締め切りの近いタスクから片付けたいという声に応えて、タスクの一覧（画面と API）を「期限の近い順」に並べ替えられるようにします。既定は今までどおり登録順です。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| 一覧の画面 | 登録順のみ | 「並べ替え」で「登録順」「期限の近い順」を選べる。ステータスの絞り込みと組み合わせられる |
| `GET /api/tasks` | `status` で絞り込み | `sort=id`（既定）・`sort=due` を追加。期限が同じタスクは登録順 |
| 不正な `sort` の値 | — | コーディング規約 2 のとおり「指定なし」（登録順）として扱う |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 並べ替え（既定・期限順・同じ期限・絞り込みとの組み合わせ）と、`sort` の値の検証の単体テストを追加した。
