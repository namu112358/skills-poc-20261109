# PR: タスクの一覧を CSV でダウンロードできるようにする

## 概要

週次の報告でタスクの一覧を Excel に貼り付けているという声に応えて、タスクの一覧を CSV でダウンロードできる API を追加します。画面のボタンは別の PR で追加します。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| CSV の出力 | できない | `GET /api/tasks/export` で CSV（見出し + 1 タスク 1 行。ID・タイトル・ステータス・担当者・期限）をダウンロードできる。ログインが必要 |
| 絞り込み | — | 一覧と同じく `?status=` で絞り込める（不正な値は、一覧と同じく「指定なし」） |
| Excel での表示 | — | UTF-8 の BOM を付け、Excel でそのまま開いても文字化けしない |
| タイトルの記号 | — | タイトルにカンマ・引用符・改行が含まれていても、列がずれないようにする |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 見出しと行の数、カンマ・引用符のエスケープ、空の一覧の単体テストを `tests/export.test.ts` に追加した。
