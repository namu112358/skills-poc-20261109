# PR: タスクに優先度（高・中・低）を付け、一覧で絞り込めるようにする

## 概要

急ぎのタスクを見分けたいという声に応えて、タスクに優先度（高・中・低）を付けられるようにします。一覧（画面と `GET /api/tasks?priority=`）で優先度で絞り込めます。今後も「カテゴリ」などの項目を足しやすいよう、項目の定義を登録する仕組みを用意しました。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| 優先度 | 無い | 高（high）・中（medium）・低（low）。既存のタスクと、指定しないで作ったタスクは「中」 |
| 作成・更新（API） | — | `priority` を指定できる。不正な値は 400 |
| 一覧 | ステータスで絞り込み | 優先度でも絞り込める（不正な値は指定なし）。一覧に優先度の列を表示 |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 優先度の既定値・作成・絞り込み・検証の単体テストを追加した。
