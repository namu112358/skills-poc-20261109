# PR: タスクの集計（合計・期限切れ・今日が期限・期限が近い）を返す API を追加する

## 概要

ダッシュボードに数字を出すため、タスクの集計を返す API（`GET /api/tasks/summary?soonDays=7`）を追加します。日付は日本時間で数えます。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| 集計 | 無い | 合計・期限切れ・今日が期限・期限が近い（明日から soonDays 日後まで）の件数を返す。完了したタスクは期限の数に入れない |
| soonDays | — | 1〜90 の整数（既定 7）。範囲外は 400 |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 集計と日数の検証の単体テストを `tests/summary.test.ts` に追加した。
