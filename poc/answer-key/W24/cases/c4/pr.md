# PR: 期限が近いタスクを一覧で目立たせる

## 概要

期限を過ぎてから気づくことが多いという声に応えて、タスクの一覧で、期限が近い未完了のタスクに「（期限間近）」と表示します。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| 一覧の期限の列 | 日付だけ | 期限が**今日から 3 日以内**（今日・明日・明後日・3 日後）の未完了のタスクに「（期限間近）」を付ける。完了したタスクと、期限を過ぎたタスクには付けない |
| 日付の数え方 | — | 利用者は日本にいるので、日本時間の日付で数える |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 残り日数と「期限間近」の判定の単体テストを `tests/due.test.ts` に追加した。
