# PR: 計測器ごとの点検担当者・点検周期・点検記録を追加

## 依頼

計測器ごとに、定期点検の担当者と点検の記録を持てるようにしてほしい。

## 合意した要件（依頼者との確認で決まったこと）

- 担当者は台帳の利用者のうち在籍している人から、1 台につき 1 人選ぶ。退職・休職中の人は新しく選べないが、すでに担当になっている計測器はそのまま表示する。
- 既存の点検者と最終点検日は引き継ぐ。名前が利用者と分かるもの（「鈴木さん」など）は、その人を担当者にする。分からないもの（「外部委託」など）は、元の書き方を残して担当者は未設定にする。日付が読めないものも元の書き方を残し、黙って捨てない。
- 点検の記録の項目は、点検日・点検した人（在籍している利用者）・結果・メモ。結果は「良好」か「要修理」で、1 台につき何回分も履歴として残す。点検した人は担当者以外でもよい。
- 「要修理」になったら、その計測器は使用停止にする（校正の不合格と同じ扱い）。
- 点検の周期は計測器ごとに月単位で持ち、決めていなければ 3 か月。次の点検予定日は「最後の点検日 + 周期」。点検の記録が 1 回も無い計測器は「未点検」として目立たせる。
- 台帳の利用者のうち在籍している人なら、誰でも担当者に選べる。

## 変更内容

- マイグレーション 6: instruments に inspector_id / inspection_interval_months（既定 3）/ legacy_inspected_on、inspections テーブルを追加
- 旧台帳の extra.inspector / last_inspected のうち読めるもの（「鈴木さん」、R8.9.10 など）だけ引き継ぎ、extra は書き換えない
- 点検記録 API: GET/POST /api/instruments/:id/inspections。要修理なら使用停止（廃棄済みは変えない）
- 担当者は在籍中の利用者のみ新規選択可（既存の担当者が退職・休職でも表示・維持）
- 次の点検予定日 = 最後の点検日 + 周期。記録が無い計測器は「未点検」と表示
- 一覧・詳細画面に担当者、次回点検、点検記録を表示
