# 定型回答（開発ワークフロー共通）

PoC の試行は無人（ヘッドレス）で実行するため、候補からの確認質問にその場で答えることはできない。
そのため、全候補・全シナリオで課題文の末尾に次の一文を付ける。

> この作業は無人で実行しています。確認の質問には答えられないので、課題文に書かれていないことはお任せします。作業が終わったら、変更内容を git にコミットしてください。

シナリオ固有の回答（W3 の要件確認など）は、そのシナリオの課題ファイルに追記する。

## W3（曖昧な要望から要件を固める）

W3 は質問を引き出せるかを測るため、回答を課題文に連結しない（連結すると隠れ要件が最初から見えてしまう）。
代わりに、課題文の末尾に次の一文を付け、候補が質問したときだけ、依頼者役（`poc/scripts/answer_w3.py`）が定型回答シートから答えて次のメッセージとして返す。

> この作業は無人で実行しています。質問には、依頼者の代わりに定型の回答シートから答えます（シートに無いことは「お任せします」と答えます）。

定型回答シートは隠れ要件そのものなので、採点用の正解データ（`poc/answer-key/W3/answers.md`）に置き、試行の作業用コピーには入れない。
