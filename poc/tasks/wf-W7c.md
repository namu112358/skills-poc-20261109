ログイン中のユーザーが、自分の作業記録を日付ごとに見られるようにしてください。「その日にどのタスクに何分使ったか」を振り返るための画面と API です。仕様は次のとおりです。

## 前提

- 作業記録（タスクに作業時間を記録する機能。`/api/tasks/:id/worklogs`）は実装済みのものを使う。作業記録のデータや既存の API の動作は変えない。
- 「日付」は、利用者（日本のチーム）にとっての日付とする。

## API

ログインが必要。未ログインなら 401 を返す。

| メソッドとパス | 動作 | 成功時 |
|---|---|---|
| `GET /api/me/worklogs?date=YYYY-MM-DD` | ログイン中のユーザーが、指定した日付に記録した作業記録を、記録日時の古い順（同じなら ID の小さい順）に返し、作業時間の合計も返す | 200 `{ "date": "2026-11-10", "worklogs": [ ... ], "totalMinutes": 90 }`（無ければ空配列と 0） |

- `worklogs` の各要素は、既存の作業記録と同じ JSON（`id`・`taskId`・`author`・`authorName`・`minutes`・`note`・`recordedAt`）に、タスクの名前 `taskTitle` を足したもの。
- ほかの人の作業記録は含めない。
- `date` が無い、`YYYY-MM-DD` の形でない、または存在しない日付（例: `2026-02-30`）のときは 400。

## 画面（/my/worklogs?date=YYYY-MM-DD）

- ログインが必要（未ログインならログイン画面へ移動する）。
- 見出し「自分の作業記録」と、指定した日付を表示する。`date` が無い・正しくないときは「日付を YYYY-MM-DD の形で指定してください。」と表示する（一覧は出さない）。
- その日の作業記録を API と同じ順に並べる。各記録は `data-testid="my-worklog"` の要素とし、タスクの名前（タスク詳細画面へのリンク）・作業時間（例: 30 分）・メモ・記録日時を表示する。
- 合計を `data-testid="my-worklog-total"` の要素に「合計 90 分」の形で表示する。記録が無いときは「この日の作業記録はありません。」と表示する。
- 日付を切り替える操作（前の日・次の日のリンクなど）は、今回は作らない。
