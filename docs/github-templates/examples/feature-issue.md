### 概要

申請が差し戻されたとき、申請者が内容を修正して、同じ申請のまま再提出できるようにする。

### 背景・課題

現在、差し戻された申請は編集できず、申請者は新しい申請を一から作り直している。
月に 30 件ほど発生しており、入力の手間に加えて、承認者は過去のやり取り（差し戻し理由など）を別の申請までさかのぼって確認する必要がある。

### 期待する動作

- 差し戻された申請の詳細画面に「修正して再提出」ボタンが表示される
- 申請者は差し戻し理由を見ながら内容を修正し、再提出できる
- 再提出された申請は、差し戻した承認者のもとに再び届く
- 承認者は同じ申請の履歴として「差し戻し → 修正 → 再提出」の流れを確認できる

### 受入条件

- [ ] 差し戻し状態の申請だけ、申請者本人が編集・再提出できる（承認者・他の社員は編集できない）
- [ ] 再提出すると、申請は差し戻した承認者の「承認待ち」一覧に表示される
- [ ] 申請の履歴に、差し戻し理由と再提出日時が残る
- [ ] 承認済み・却下済みの申請は、これまでどおり編集できない

### 補足・制約（任意）

- 対象外: 再提出の回数制限、承認者の変更
- 状態遷移は申請ドメインの既存ルールに追加する形にしたい（関連: `src/approval/`）。実装方針は `docs/plans/123-resubmit.md` を参照
