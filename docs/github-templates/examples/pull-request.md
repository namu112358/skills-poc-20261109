## 概要

差し戻された申請を、申請者が修正して、同じ申請のまま再提出できるようにしました。

## 背景・目的

差し戻しは月に 30 件ほどあります。そのたびに申請者は内容を一から入力し直しています。承認者も、差し戻し理由などの過去のやり取りを確認するために、元の申請までさかのぼる必要がありました（#123）。

## 変更内容

- 変更前: 差し戻された申請は編集できず、申請者は新しい申請を作り直していた。新しい申請は承認者の一覧に新規として並び、過去の経緯は元の申請を開かないと分からなかった
- 変更後:
  - 差し戻された申請の詳細画面に「修正して再提出」ボタンが表示される（申請者本人にだけ表示）
  - 再提出すると、差し戻した承認者の「承認待ち」一覧に戻る
  - 申請の履歴に「差し戻し理由」と「再提出日時」が残り、同じ申請の中で経緯を追える

実装メモ: 申請の状態に「差し戻し → 再提出」の遷移を追加し、権限チェックは既存の申請者判定を再利用しています。
