## 概要

差し戻された申請を、申請者が修正して同じ申請のまま再提出できるようにしました。これまでは新しい申請を作り直す必要がありました。

## 変更内容

- 差し戻された申請の詳細画面に「修正して再提出」ボタンを追加（申請者本人にのみ表示）
- 再提出すると、差し戻した承認者の「承認待ち」一覧に戻るようにした
- 申請の履歴に「差し戻し理由」と「再提出日時」を表示するようにした

実装メモ: 申請の状態に「差し戻し → 再提出」の遷移を追加し、権限チェックは既存の申請者判定を再利用しています。
