### 発生している問題

承認者が「承認待ち」一覧から申請を開くと、申請者が添付した見積書などのファイルが表示されず、内容を確認できないまま承認判断を求められている。

### 期待する動作

申請詳細画面に添付ファイルの一覧が表示され、クリックするとファイルを開ける。

### 実際の動作

添付ファイル欄が空のまま表示される。申請者本人が同じ申請を開くと正しく表示される。エラーメッセージは出ない。

### 再現手順

1. 社員 A でファイルを 1 つ添付して申請を作成し、提出する
2. 承認者 B でログインし、「承認待ち」一覧から 1 の申請を開く
3. 添付ファイル欄が空になっている

### 発生環境

ステージング / Chrome 130 / macOS 15 / main@abc1234

### 発生頻度

毎回

### 補足情報（任意）

- 11/5 のリリース以降に発生。承認者は申請者に別途メールでファイルを送ってもらって回避している
- ブラウザの開発者ツールでは、添付ファイル取得の通信が権限エラー（403）になっている。承認者の閲覧権限の判定が原因と推測
