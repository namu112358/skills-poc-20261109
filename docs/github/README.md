# GitHub の設定

新規プロジェクトの GitHub まわりの標準を説明する文書です。配るファイルそのものは `templates/github/` にあります。

| 文書 | 内容 |
|---|---|
| [setup/README.md](setup/README.md) | 新規リポジトリの初期設定の手順（Rulesets、Advanced Security、Actions、Environments、標準ファイル）と、AI エージェントが品質ゲートを迂回できないようにする権限設計 |
| [setup/rulesets/](setup/rulesets/README.md) | このリポジトリの `main` に適用している Ruleset の定義 |
| [templates/README.md](templates/README.md) | Issue・PR のテンプレートで決めたこと、導入手順、記入済みのサンプル（[examples/](templates/examples/)） |
| [templates/research.md](templates/research.md) | テンプレートを決めるための調査結果と出典 |
| [../github-writing.md](../github-writing.md) | Issue・PR の書き方（AI エージェント・人間共通）。各プロジェクトに `docs/github-writing.md` として配るので、雛形と同じ場所に置いている |
