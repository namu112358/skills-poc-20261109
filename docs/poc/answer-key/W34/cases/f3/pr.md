# PR: タスクの期限を延長できるようにする

## 概要

取引先の都合で締め切りが延びることが多いという声に応えて、タスクの期限を日数で延長できるようにします（`POST /api/tasks/:id/extend`）。画面のボタンは別の PR で追加します。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| 期限の延長 | できない | `{ "days": n }` で、期限を n 日延ばす。n は 1〜30 の整数（範囲外・整数でなければ 400）。月・年をまたいでよい |
| 完了したタスク | — | 延長できない（400） |
| 無いタスク | — | 404 |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 延長の計算・入力の検証・延長の処理の単体テストを `tests/extend.test.ts` に追加した。
