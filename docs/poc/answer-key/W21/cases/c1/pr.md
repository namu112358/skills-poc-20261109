# PR: タスクに「保留」のステータスを追加する

## 概要

取引先の返事待ちなどで、手を付けられないタスクを「進行中」と区別したいという声に応えて、タスクのステータスに「保留」を追加します。一覧の絞り込み・タスクの作成と更新（API）で「保留」を選べるようになります。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| ステータス | 未着手・進行中・完了 | 未着手・進行中・**保留**・完了（API の値は `on_hold`） |
| 一覧の絞り込み | 3 種類 | 「保留」でも絞り込める |
| `POST /api/tasks`・`PATCH /api/tasks/:id` | `status` は 3 種類 | `on_hold` も受け付ける |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 入力の検証で `on_hold` が通ることの単体テストを追加した。
