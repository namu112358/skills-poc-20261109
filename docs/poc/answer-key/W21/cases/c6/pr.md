# PR: 自分のアカウントを、すべての端末からログアウトできるようにする

## 概要

共用の端末でログアウトし忘れたかもしれない、という問い合わせに応えて、利用者が自分のアカウントを、すべての端末（ほかのブラウザ・PC を含む）から一度にログアウトさせられる API を追加します。画面のボタンは別の PR で追加します。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| ログアウト | 今のブラウザだけ（`POST /api/logout`） | `DELETE /api/users/:id/sessions` で、そのユーザーのすべてのセッションを無効にする。**本人だけが実行できる**。成功は 204、ユーザーが無ければ 404、未ログインは 401 |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 指定したユーザーのセッションだけが消えることの単体テストを追加した。
