# PR: 担当者が変わったときに、変更の記録をサーバーのログに残す

## 概要

監査の担当から「タスクの担当者がいつ誰から誰に変わったかを追えるようにしてほしい」と依頼があったため、担当者が変わったときに、サーバーのログに 1 行の記録を残します。記録先は当面サーバーのログだけでよい、という合意です（ほかの記録先にする予定は今のところありません）。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| 担当者の変更 | 記録しない | 担当者が変わったときに `[audit] task <ID>: assignee <前> -> <後> at <日時>` をログに出す。担当者が変わらない更新では出さない |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 通知の仕組み（イベントの購読と送り先の作成）の単体テストを `tests/notify.test.ts` に追加した。
