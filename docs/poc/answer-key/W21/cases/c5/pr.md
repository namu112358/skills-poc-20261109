# PR: タスクの担当者の項目名を、利用者の ID であることが分かる名前にする

## 概要

担当者の項目（`assignee`）に、利用者の名前と ID のどちらが入るのかが紛らわしく、画面で名前を出すところで取り違えが起きかけたため、コードと DB の名前を `assigneeId`・`assignee_id` に揃えます。内部の名前の整理なので、**画面の表示と API の入出力は変えません**。

## 変更内容

| | 変更前 | 変更後 |
|---|---|---|
| コード上の項目名 | `Task.assignee` | `Task.assigneeId` |
| DB の列名 | `tasks.assignee` | `tasks.assignee_id`（新しいマイグレーション 3 で名前を変える。データはそのまま） |
| 画面・API | — | 変えない |

## 検証結果

- `npm run typecheck`・`npm test` が通ることを確認した。
- 既存のテストの項目名を新しい名前に合わせた。
