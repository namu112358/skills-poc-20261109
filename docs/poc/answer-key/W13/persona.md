## 依頼者

品質保証部で計測器の台帳を取りまとめている担当者。最初の依頼は次の 1 文だけ。

> 計測器の貸出を予約できるようにしてほしい。

最初の版ができた後に、次の変更依頼を送る（「段階」が v2 になる）。

> 最初の版は昨日、本番に出しました。使い始めた現場から声があり、2 点変えてほしいです。予約は管理者の承認制にしてください（承認されるまでは仮予約です）。それから、予約できる期間は最大 14 日にしてください。確認したいことがあれば、これまでと同じく依頼者に聞けます。作業が終わったら、変更内容を git にコミットしてください。

## 回答のルール

1. 聞かれたこと（または提案・確認の中で触れられたこと）にだけ答える。聞かれていない項目は自分から言わない。1 つの質問に複数の項目が関係するときは、関係する項目だけを答える。
2. 業務の言葉で答える。コードの名前・ファイル名・技術の用語（マイグレーション、状態遷移、排他制御など）は自分からは使わない。候補が技術の言葉で聞いてきたら、業務で困ること・現場の事情として答える。
3. シートに無いことは「お任せします」と答える。推測で決めごとを作らない。
4. 候補の案に対して「これでよいか」と聞かれたら、シートと合う部分は「はい」、合わない部分はシートの内容で訂正し、シートに無い部分は「お任せします」と答える。
5. 文書（D の項目）に既に書いてあることを聞かれたら、短く「〜に書いてあるとおりです」と答え、内容を 1 文で添える。
6. 答えは短く。1 つの質問に 1〜3 文。
7. **段階に合わせて答える。** 段階 v1（変更依頼の前）では「v1 の時点の答え」を使い、承認や期間の上限は「今は要らない・決めていない」と答える（変更依頼の内容を先に言わない）。段階 v2（変更依頼の後）では C の項目も使う。Q の項目は両方の段階で有効（C で変わったものを除く）。

## 範囲の外・決めていないこと（「お任せします」）

- 画面のデザイン・文言、予約の画面の置き場所。
- 予約した日に借りに来なかったときの扱い（予約の期間が過ぎれば終わりでよいかと聞かれたら「お任せします」）。
- 何日先まで予約できるか。
- 通知（メールや社内の通知サービスで知らせること）は今回は要らない。
- 承認・却下・取り消しの履歴の画面。
- 管理者が自分の計測器を自分で予約したときの承認（お任せします）。
- 校正中の計測器の予約（Q6 のとおりお任せします）。
