# W18 第 2 回「貸出の予約」の回答シート

> 計測器の貸出を予約できるようにしてほしい。

W13 の回答シート（`docs/poc/answer-key/W13/persona.md`、出どころ: `origin/agent/poc-w13` のコミット a0617be）の Q1〜Q11 と「v1 の時点の答え」を写し、W18 で Q12（第 1 回の校正期限を使う決まり）を足した。W13 の変更依頼の後の決まり（C）は使わない。隠しテストは `f2.cjs`（K 項目）。


## 業務の決まり（Q。隠れ要件。隠しテストの K 項目と対応）

| ID | 内容 | 隠しテスト |
|---|---|---|
| Q1 | 予約は日単位。開始日と終了日を決め、両端の日を含む（11/20〜11/22 なら 3 日間）。日付は日本時間で考える。 | K02 |
| Q2 | 過去の日からは予約できない（今日からは予約できる）。終了日は開始日より前にできない。 | K01 |
| Q3 | 同じ計測器で、期間が 1 日でも重なる予約はできない（前の予約の終了日と、次の予約の開始日が同じ日も重なりに入る）。取り消した予約は数えない。 | K02・K03 |
| Q4 | 貸出中の計測器は、返却予定日の翌日からなら予約できる。返却予定日までの日と重なる予約はできない。 | K04 |
| Q5 | 予約が入っている期間にかかる貸出は、予約した本人以外にはしない（貸出の今日〜返却予定日に、他人の予約の日が 1 日でも入るなら貸さない）。予約した本人には、予約の期間の中なら貸し出せる。現場で「予約していたのに、ほかの人が持っていってしまった」という苦情があったため。 | K05 |
| Q6 | 使用停止・廃棄の計測器は予約できない。校正中の計測器の予約はお任せします。 | K06 |
| Q7 | 予約を取り消せるのは、予約した本人と、その計測器の管理者。ほかの人は取り消せない。 | K07 |
| Q8 | 校正で不合格になって使用停止になった計測器の、これからの予約は取り消しにしてほしい（予約した人には管理者が連絡する）。 | K08 |
| Q9 | 予約するのはログインしている本人（ほかの人の代わりに予約することはない）。誰でも予約できる（部署は問わない）。 | （テストなし） |
| Q10 | 計測器の詳細で、これからの予約（取り消したものは除く）を、誰が・いつからいつまで、で見たい。 | P01 |
| Q11 | 同じ人が同じ計測器を、期間が重ならなければ何件予約してもよい。 | （テストなし） |
| Q12 | 校正期限（前回校正日に校正周期を足した月の末日。第 1 回で決めたもの）を過ぎた日は予約できない。期限の当日までは予約できる。期限切れの計測器を現場で使わせないため。 | K09 |

- 校正中の計測器の予約（Q6 のとおりお任せします）。
