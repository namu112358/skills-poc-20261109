# W18 第 3 回「設置場所のマスタ化」の回答シート

依頼文（`docs/poc/tasks/wf-W18r3.md`）:

> 計測器の設置場所を、自由入力ではなく、場所の一覧から選ぶ形にしたい。

隠しテストは `f3.cjs`（L01〜L07）と `f3-upgrade.cjs`（L08）。

## 業務の決まり（Q。隠れ要件）

| ID | 内容 | 隠しテスト |
|---|---|---|
| Q1 | 場所の一覧（工場・建屋・部屋など）を台帳の中で管理したい。場所を追加できるようにしてほしい。誰が追加できるかは、今はお任せします。 | L01 |
| Q2 | 同じ場所が二重に登録されると困る。空白のあり・なしや、全角・半角（数字・空白）の違いだけの名前は、同じ名前とみなして登録させないでほしい（例:「製造部 第1ライン」「製造部　第１ライン」「製造部第1ライン」は同じ）。 | L01 |
| Q3 | 今入っている計測器の設置場所は、場所の一覧に移してほしい。空白のあり・なしや、全角・半角（数字・空白）の違いだけのものは 1 つの場所にまとめる。それ以外の違い（「第一」と「第1」など）はまとめなくてよい（別の場所として移し、あとで品質保証部が整理する）。まとめた場所の名前は、どれか 1 つの書き方でよい（お任せします）。設置場所が空の計測器は「未設定」のままでよい。 | L08 |
| Q4 | 設置場所が決まっていない計測器もある（未設定でよい。今も任意）。 | （テストなし） |
| Q5 | 計測器の一覧・詳細の「設置場所」には、場所の名前を出してほしい。データ連携で計測器の API を読んでいるほかのシステム（ハンディ端末アプリ）があり、設置場所を `location`（名前の文字列）で読んでいるので、そのまま名前で読めるようにしてほしい。 | L02 |
| Q6 | ハンディ端末アプリは今月中は古い版のままで、計測器の登録・編集のときに設置場所を名前の文字列（`location`）で送ってくる。場所の一覧にある名前（Q2 の表記ゆれを含む）なら受け付けてその場所にし、一覧に無い名前は受け付けない（エラーにして、現場に一覧への追加を頼んでもらう）。 | L03 |
| Q7 | 場所の名前を変えたら（部屋の名前が変わるなど）、その場所の計測器の設置場所も新しい名前で出てほしい。 | L04 |
| Q8 | 使わなくなった場所は一覧から消したい。ただし、計測器が置かれている場所は消せないようにしてほしい。 | L05 |
| Q9 | 計測器の一覧を、場所で絞り込めるようにしてほしい（「この部屋にある計測器」を見たい）。 | L06 |
| Q10 | 校正期限のお知らせ（第 1 回）に入れている設置場所も、場所の一覧の今の名前にしてほしい。 | L07 |

| ID | 内容 | 場所 |
|---|---|---|

| D2 | 計測器の項目（設置場所は今は自由入力）と API の書き方 | `CLAUDE.md`・既存のコード |

## 範囲の外・決めていないこと（「お任せします」）

- 場所の階層（工場 > 建屋 > 部屋）。今回は 1 段の一覧でよい。
- 場所の一覧の画面のデザイン、並び順。
- 場所の名前の長さの上限、場所に付ける項目（コード・備考など）。
- 誰が場所を追加・変更・削除できるか（今はお任せします）。
