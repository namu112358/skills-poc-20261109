# W18 第 5 回「変更履歴（監査ログ）」の回答シート

依頼文（`docs/poc/tasks/wf-W18r5.md`）:

> 監査で指摘があったので、計測器ごとに、誰がいつ何を変えたかの履歴を見られるようにしてほしい。

隠しテストは `f5.cjs`（A01〜A09）。

## 業務の決まり（Q。隠れ要件）

| ID | 内容 | 隠しテスト |
|---|---|---|
| Q1 | 履歴に残すのは、その計測器の台帳を変える操作すべて: 台帳の登録・編集（重要度・設置場所を含む）、貸出・返却、校正記録の登録、予約の作成・取消、校正の発注（受付システムが受け付けたことを含む）。 | A01〜A06 |
| Q2 | 「誰が」は利用者、「いつ」は日時、「何を」は、項目ごとに変更前の値と変更後の値が分かるようにしてほしい（例: 名称を A から B に）。 | A01 |
| Q3 | 定期実行のジョブなど、人ではなく仕組みが変えたものは「システム」として残す。 | （テストなし） |
| Q4 | 監査のため、履歴は後から変えたり消したりできないようにしてほしい。 | A08 |
| Q5 | 計測器の詳細で、新しい順に見たい。データを取り出すため API でも取れるとよい。 | A09 |
| Q6 | 失敗した操作（入力の誤りで断られたものなど）は、何も変わっていないので残さなくてよい。 | A07 |
| Q7 | 設置場所の変更は、場所の名前で残してほしい。後で場所の名前を変えても、履歴は当時の名前のままにしてほしい（監査で「当時どこにあったか」を見るため）。 | A02・A09 |
| Q8 | 校正記録を登録して状態や前回校正日が変わったとき（不合格で使用停止など）は、その変化も分かるようにしてほしい。 | A04 |
| Q9 | この機能を入れる前の分の履歴は無くてよい。 | （テストなし） |

## 運用の事情（O）

| ID | 内容 |
|---|---|
| O1 | 本番の DB には 2024 年からのデータが入っている。リリースでデータが消えたり変わったりしないようにしてほしい。 |
| O2 | 履歴はずっと残しておきたい（消す予定はない）。 |

## 文書・既存の仕組みに既に書いてあること（D）

| ID | 内容 | 場所 |
|---|---|---|
| D1 | 計測器の項目・状態、貸出・校正記録・予約・発注の仕組み | `CLAUDE.md`・既存のコード |

## 範囲の外・決めていないこと（「お任せします」）

- 場所の一覧（マスタ）そのものの変更の履歴、利用者・部署の変更の履歴。
- 履歴の画面のデザイン、絞り込み・検索、CSV の出力。
- 閲覧（見ただけ）の記録。
- 誰が履歴を見られるか（今はお任せします）。
