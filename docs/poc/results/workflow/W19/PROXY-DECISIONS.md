# W19 の準備で、人間の代理人が下した判断

- 代理人: 独立のサブエージェント（Sonnet）。判断の原則は `docs/poc/proxy/principles.md`（ユーザーとの相談で示された考え方。特定の W の正解は書かない）。
- ユーザーの指示（2026-11-10）: 「基本的に自律型開発をするつもりだから、質問や議論は、人間の代理人を置いて確認してみて。代理人は、どのような決定を下したのか、人間に報告できるようにしておいて。」
- 担当（この準備をする AI）が人に聞きたくなる判断を、代理人に聞いて決めた。試行の中の代理人の判断は、各試行の `raw/<試行ID>/po-questions.jsonl` の `decisions` に残り、report にまとめる。
