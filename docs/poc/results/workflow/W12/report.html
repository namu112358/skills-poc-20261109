計算方法と判断の記録

  • 品質 = （業務の受け入れ 30 + DB マイグレーション 20 + 外部呼び出しの堅牢さ 15 + 運用 10 + 設計の筋 15 + テストの強さ 10）の得点 ÷ 100 × 100。
  • 効率 = 費用 50 + 時間 30 + 介入 20。費用・時間は baseline（$0.8534・267.5 秒）に対する倍率で、2 倍以下 = 満点、3 倍以下 = 80%、5 倍以下 = 60%、10 倍以下 = 30%、10 倍超 = 0。介入は 0 回 = 20、1 回 = 10、2 回以上 = 0。
