この作業ブランチには、レビュー待ちのプルリクエストに相当する変更が、未コミットの差分として入っています（`git diff HEAD` で見られます。新しいファイルも含みます）。PR の説明は下のとおりです。この変更をコードレビューし、マージ前に直すべき問題を指摘してください。

- 指摘はリポジトリ直下の `REVIEW.md` に書き、`REVIEW.md` だけを git にコミットしてください。コードは直さないでください（今回はレビューだけを依頼しています）。
- 指摘ごとに、場所（ファイルと関数・行）、何が問題か（どういう入力・状況で何が起きるか）、直し方を書いてください。重要度（高・中・低）も付けてください。
- 問題が無いと判断した点は書かなくてかまいません。
