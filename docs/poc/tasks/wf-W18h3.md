計測器の状態に「修理中」を足してください。故障して修理業者に出している間の状態です。今は使用停止で代用していますが、校正の不合格と区別できず困っています。

- API の状態の値は `repairing`、画面の表示は「修理中」。台帳の編集で、使用中・使用停止の計測器を修理中にでき、修理中から使用中・使用停止に戻せる。一覧を状態で絞り込むときにも選べるようにする。
- 修理中の計測器は、貸出も予約もできない。修理中にしたときは、校正で不合格になったときと同じように、その計測器のこれから（終了日が今日以降）の予約を取り消す。
- 修理中の計測器には、校正期限のお知らせを送らない（校正中・使用停止と同じ）。
- 修理中の計測器は、校正機関に発注できない（修理から戻ってから発注する）。
- 修理中にする・戻すのは、ほかの状態の変更と同じ扱い（変更履歴に残す。台帳を編集できる人だけができる）。
- 本番の DB には 2024 年からのデータが入っている。リリースでデータが消えたり変わったりしないようにする。
