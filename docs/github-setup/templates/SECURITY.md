# セキュリティポリシー

## 脆弱性の報告

脆弱性を見つけた場合は、公開の Issue や PR ではなく、GitHub の非公開の報告フォームから連絡してください。

- 報告フォーム: リポジトリの **Security → Report a vulnerability**（https://github.com/OWNER/REPO/security/advisories/new）

報告には、影響を受けるバージョン、再現手順、想定される影響を含めてください。

## 対応

- 受領の連絡: 3 営業日以内
- 初回の評価結果の連絡: 10 営業日以内
- 修正後、必要に応じて GitHub Security Advisory を公開します。
